# T10 拖拽物理手感 —— 需求文档

> 状态：开发中（2026-09-07）
> 前置：T1 尺寸自适应（多屏/DPI）已完成，反弹边界直接复用 current_screen()

## 1. 目标

把现有「松手即停」的拖拽升级为**有物理手感**的交互：

| 现状 | T10 后 |
|---|---|
| 松手后宠物停在原地 | 松手时若有速度 → 甩抛出去，受重力下落 |
| 无边界概念 | 贴地弹跳、撞墙反弹，多次衰减后停下 |
| 拖到哪是哪 | 轻放（速度低于阈值）行为不变，位置照常保存 |

## 2. 交互设计

### 2.1 甩抛（fling）

- 拖拽过程中持续采样指针位置（`feed`）
- 释放时取**最近 100ms 采样窗口**的平均速度作为初速度
- 初速度 ≥ 350 px/s → 进入飞行（flying）；否则视为轻放，走原有逻辑
- 方向即拖拽末段方向：往上甩 → 抛物线上抛；往侧面甩 → 平抛贴地滑

### 2.2 弹弓（slingshot）

与甩抛统一模型：**释放速度 = 采样窗口内位移 / 时间**。
- 快速甩 = 大速度 = 甩抛
- 按住拉满慢慢松 = 小速度 = 轻放/短滑
不做独立的「拉弓蓄力」状态机 —— 交互上两种手感天然由同一公式覆盖。

### 2.3 反弹（bounce）

| 边界 | 行为 |
|---|---|
| 底部（任务栏上沿） | 垂直速度 × restitution(0.35) 反弹；水平速度 × 0.8（摩擦） |
| 左右屏幕边缘 | 水平速度 × 0.5 反弹 |
| 顶部 | 往下弹（速度 × restitution） |

**静止判定**：贴地 且 |vy| < 40 px/s 且 |vx| < 20 px/s → 落地静止，
保存位置到 settings，回 idle，恢复眨眼/行为调度。

## 3. 参数表（drag_physics.py 顶部常量，可调）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `GRAVITY` | 3000 px/s² | 屏幕坐标系，向下为正 |
| `RESTITUTION` | 0.35 | 垂直反弹系数（0=完全吸能） |
| `WALL_BOUNCE` | 0.5 | 水平撞墙反弹系数 |
| `GROUND_FRICTION` | 0.8 | 每次落地水平速度保留比 |
| `MIN_THROW` | 350 px/s | 低于视为轻放 |
| `SAMPLE_WINDOW` | 0.10 s | 释放速度采样窗口 |
| `MAX_SPEED` | 4000 px/s | 速度上限（防一次甩出屏） |
| `SETTLE_VY` / `SETTLE_VX` | 40 / 20 px/s | 静止阈值 |

## 4. 架构

```
drag_physics.py        纯逻辑层：状态机 idle→dragging→flying→idle
  ├── start_drag(x, y)          进入拖拽，清空采样
  ├── feed(x, y, t)             拖拽中采样（main 的 mouseMoveEvent 调）
  ├── release() → (vx, vy, flying)   算初速度；flying=False 即轻放
  ├── set_bounds(l, t, r, b)    宠物可移动区域（调用方已减去自身宽高）
  └── step(dt) → (x, y)         飞行积分一步（半隐式欧拉 + 反弹）；
                                 静止后 state 回 idle，step 返回最终位置
```

- **禁 import PySide6**（纯逻辑层红线，tests/test_architecture.py 已有检查）
- 时间用 `time.monotonic()`，测试可注入 t
- dt 内部 clamp 到 [0, 0.05] 防大步长穿透

main.py 集成（改动集中在鼠标三事件 + 一个新 QTimer）：

| 位置 | 改动 |
|---|---|
| `mousePressEvent` 拖拽阈值分支 | `self._phys.start_drag(x, y)` |
| `mouseMoveEvent` 拖拽分支 | `self._phys.feed(x, y)` |
| `mouseReleaseEvent` 拖拽分支 | `release()`；flying → 启动 `physics_timer`（16ms），轻放 → 原逻辑不变 |
| `physics_timer` tick | `step(0.016)` → `move()`；落地后停表、保存位置、回 idle、播 recoil（若弹跳过） |
| settings | 新增 `"drag_physics": True`（灵宠中心后续可加开关 UI） |

## 5. 不做什么

- 不做拖拽时的实时「拉伸变形」视觉效果（素材不支持）
- 不做跨屏飞行（反弹边界 = 释放时所在屏；甩到别屏停下后以新屏为边界）
- 不改 sleep/唤醒/agent_link 状态机 —— 飞行中触摸即抓（mousePress 会打断物理）
