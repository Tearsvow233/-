## L1 — 纯本地定时器 ✅

- `灵宠中心`：喝水提醒 / 久坐提醒（间隔可设 0=关闭）
- `灵宠中心 → 自定义提醒`：QListWidget 增删提醒列表
- `reminders[]` 数据结构（v3，支持三种模式）：
  ```json
  {"name":"开会","mode":"weekly","at":"20:00","weekday":1,"once":false,"enabled":true}
  {"name":"交作业","mode":"interval","interval_min":1080,"once":true,"enabled":true}
  ```
- 调度：`_setup_custom_reminders` 按 mode 建单次 QTimer；daily/weekly 触发后经
  `_fire_recurring_reminder` 按 24h/7d 重排下一次；once 提醒触发后自动停用。

## L2 — 本地 NLP-lite 解析 ✅

文件：`reminder_parser.py`（纯正则 + 中文数字，零依赖）。

**支持的语法**：
```
3分钟后提醒我喝水          -> 一次性 3 分钟后
2小时30分钟后提醒吃水果    -> 一次性 150 分钟后（多单位累加）
每天9点提醒吃药            -> 每天 09:00 循环
每天下午3点提醒我喝水      -> 每天 15:00（下午自动 +12）
15:30 提醒接孩子           -> 每天 15:30
每30分钟提醒我喝水         -> 每 30 分钟循环（once=false）
每隔2小时提醒我活动        -> 每 120 分钟循环
```

**边界设计（重要，防"半懂装懂"）**：L2 只解析有十足把握的简单句；一旦命中
以下语义 **一律返回 None 交 L3**（宁可不解析走免费 LLM，也不错解析生成错误提醒）：
- 每周一/礼拜X/每个星期X（weekly 循环）→ L3
- 明天9点/今晚11点/下周三/后天（一次性绝对时刻）→ L3
- 泛化请求"我想要个提醒" → None → 提示换说法

实测单测：14 组语法 + 15 组边界全部通过。

## L3 — LLM 解析自然语言 ✅

文件：`ai_chat.py` → `PetAI.parse_reminder_spec(user_text)`。

**架构（LLM 只报时间意图，日期差本地算）**：
1. system prompt 注入"今天日期/当前时间/明天日期"，temperature=0
2. LLM 输出 JSON：name / mode(interval|daily|weekly) / at / weekday / interval_min / datetime
3. `_normalize_spec` 本地二次校验：
   - 原句含一次性指示词（明天/今晚/下周三…）→ 一律转一次性 interval
   - 原句明确"每/每隔 N 分钟"才允许循环（once=false），其余 interval 一律 once=true
   - **周几一次性提醒（下周三X点）日期由本地 `_next_weekday_at` 精确推算**，
     不信 LLM 算的日期（实测 LLM 把"下周三"错算成 9/10，本地算正确 9/9）
   - 一次性提醒附带 `at_text`（"明天 09:00"），气泡/列表显示人性化时间
     而非"1081 分钟后"

**调用链（两处入口共用）**：`parse_reminder(L2)` → 失败 → `ReminderParseWorker`
（QThread 异步，不卡 UI）→ `parse_reminder_spec(L3)` → 成功入库 / 失败提示换说法。
- 托盘菜单 `⏰ 快速提醒…`（PetWindow）
- 灵宠中心 `＋ 添加提醒`（PetCenter，未启用 AI 时回退手动间隔弹窗）

**验证**：7 组端到端真实 API 全绿——每周一晚上8点→weekly、
明天9点→明天 09:00 一次性、25分钟后→interval once、每30分钟→interval 循环、
今晚11点→今天 23:00、下周三下午2点→9月9日 14:00、每天下午3点→daily 15:00。

## 附录 A：安装包（Inno Setup）决策备忘

**结论：现阶段不建议打包安装包，继续用"绿色版"（dist 目录直接复制）。**
理由：
1. 更新频率高：本阶段几乎每轮都在改源码重打包，绿色版覆盖 exe 即可，安装包每次要跑安装流程更麻烦。
2. 单实例互斥 + 配置文件位置：当前 exe 读 exe 旁 `settings.json`；若做安装包改到 `%APPDATA%`，
   配置路径逻辑要改 + 旧配置迁移，收益不大。
3. 分发需求：只有"发给别人用"才需要安装包；自用无需。

若将来要分发：`BabyCat.iss` 脚本已备好（见项目根目录），双击 Inno Setup 编译即得
安装程序；每次发版 = `build.bat` 重打包 exe → 重新编译 iss（两步，可再写个 `release.bat` 一键）。
